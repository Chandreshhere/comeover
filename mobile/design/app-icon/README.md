# App icon

`mo-icon.svg` is the source for the app icon (Mo waving on brand blue #5B7BF5).
Render it at 1024x1024 in a browser (headless Chrome) and export:
- iOS: `ios/ProjectIRL/Images.xcassets/AppIcon.appiconset/AppIcon-1024.png` (no alpha)
- Android: `android/app/src/main/res/mipmap-*/ic_launcher.png` (48/72/96/144/192) and `ic_launcher_round.png` (circle-masked)
